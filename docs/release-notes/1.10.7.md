# 1.10.7 release notes (Android first)

*One file per version. Play takes ONE box with locale tags, each at most 500 characters, so the English is written
short enough for the French. Every block is checked by script (no dash, digit, exclamation, currency or percentage, no
Premium, price, free, review, rating or website, French no-break spaces and typographic apostrophes, real diacritics).
The UI names are the app's own, from each language's catalogue: `settings.reminderLabel`, `glance.channelName`,
`closeTheDay`, `chartACourse`, `reflectOnWeek`, `scan`.*

**Native read: not yet.** Written 2026-11-11 for the Internal testing track, where only Melroy sees it. Before the
production release, each translation gets a native read, as 1.10.1's did.

What 1.10.7 carries on Android, since 1.10.0 (the live Android version): Today in your notifications (PR #15, off by
default, a third choice under Daily reminder), the widget in Today's own order and refreshed on every save, the AI
language fix (Chart a course, Reflect on this week and Scan answer in the app's language), the new one-colour
notification icon, R8 (nothing to announce), and every app fix since (CHANGELOG, Unreleased). Premium without an
account is iPhone only and is not mentioned here. The Apple What's New for 1.10.7 follows before the App Store
submission.
