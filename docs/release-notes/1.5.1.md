# 1.5.1 release notes (paste-ready)

*The durable home for store notes, so a train never has to dig them out of a chat again. One file per
version. Play takes ONE paste with six locale tags (Spanish twice, es-419 and es-ES), each block at
most 500 characters, real diacritics. Apple takes What's New (English; the localised listings inherit
it) and an optional promotional text of at most 170 characters.*

What 1.5.1 carries over 1.5.0, for the record: the Ours clarity pass from a couple's field report
(`28dcace`, `befd743`, `6b36241`), the reopen handshake and the self-refreshing pairing screen
(`eba6fce`, `40cbb32`), the flow audit's 22 fixes (`d217619`), and the select-row layout (`0a35d65`).

## Apple, What's New

```
Ours, made clearer. The waiting screen says it is waiting and offers a new code. The Menu goes straight to Ours. The shared list shows when your person has not joined yet. A closed list reopens from its own screen: make a code for them, or enter the one they read to you. And the screen refreshes itself while you wait, so nobody is left staring at a code.

Also in this version: Remove has an Undo. Repeating tasks follow their start date. Premium says which feature brought you there. Focus opens straight on a single task instead of asking which one. The big mark stays visible while you select several. Toggles and checkboxes read properly to screen readers on the web. And a couple of dozen small words fixed where a screen said one thing and did another.
```

## Apple, promotional text (170 max)

```
Ours is clearer, Remove has an Undo, and Focus opens straight on a single task. Calm, one day at a time.
```
