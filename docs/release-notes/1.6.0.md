# 1.6.0 release notes (paste-ready)

*One file per version (see 1.5.1.md for the conventions). Play takes ONE paste with six locale tags
(Spanish twice, es-419 and es-ES), each block at most 500 characters, real diacritics. Apple takes What's
New (English; the localised listings inherit it) and an optional promotional text of at most 170
characters.*

What 1.6.0 carries over 1.5.1, for the record: Today v3 and the rooms (`dc2501e`, `f043280`), a fresh-eye
pass and Tuck (`3f06c0f`, `b4b5a08`), the floating + and its rising panel (`07b7710`), the Repeating room
and Routines starting empty (`d9e81b8`, `afc81a1`), the phone fixes (`0a216d4`, `73dac44`, `493c10a`,
`51e2845`), all merged as `e8180bd`; and, on Android only, Path C (the app sells nothing).

**The Play block must never mention Premium, a price, a trial, Stripe or the website.** It is a
Play-reviewed surface, and Path C's whole point is that the Android app sells nothing (see
`docs/play-store-release.md` section 5d). Do NOT paste `1.5.1.md`'s Play block into Play: every tag in it
mentions Premium.

## Apple, What's New

```
A calmer Today. Add anything with the + at the bottom: a panel rises, and the keyboard waits until you tap the box. Finished tasks can tuck away into a quiet Done today line, if you like, chosen once in Settings or the welcome.

Repeating tasks now have their own room, grouped by rhythm. Routines start empty, with one gentle suggestion inside each form. The Menu is a page of rooms, each with its picture, and Settings sit in five clear cards. And the whole app fits the phone better, from the keyboard to the smallest screens.
```

## Apple, promotional text (170 max)
