## Apple, What's New

```
A calmer Today. Add anything with the + at the bottom: a panel rises, and the keyboard waits until you tap the box. Finished tasks can tuck away into a quiet Done today line, if you like, chosen once in Settings or the welcome.

Repeating tasks now have their own room, grouped by rhythm. Routines start empty, with one gentle suggestion inside each form. The Menu is a page of rooms, each with its picture, and Settings sit in five clear cards. And the whole app fits the phone better, from the keyboard to the smallest screens.

Quiet, the borderless look, is now free for everyone.
```

## Apple, App Review Information and notes

Sign-in required: **Yes**. User name `appreview@doubledone.app`. Password: `No password: one-time code, see notes`.
The account is comped (`COMP_EMAILS`), so the notes send the reviewer to test the purchase SIGNED OUT,
which works because an iOS purchase needs no account (`purchaseGate` in `lib/iap.ts`, 5.1.1(v)).
Every label below was checked against `client/src/lib/catalogs/en.ts` on 2026-09-27. 1966 characters.

```
DoubleDone is a calm daily to-do app for people who find a full task list overwhelming. The daily loop is free and needs no account. Premium adds optional extras.

Version 1.6.0 redesigns the Today screen (a + button raises an add panel) and makes the Quiet look free. Nothing about purchases or sign-in has changed.

REVIEW ACCOUNT (sign-in is passwordless)
1. On Today, tap "Sync and sharing".
2. Enter appreview@doubledone.app and tap "Email me a code".
3. In any browser, open https://api.doubledone.app/review-code. It shows the latest 6-digit code.
4. Type it into the app. Codes last an hour. If none shows, tap send again in the app and refresh the page.
This account already has Premium, so every Premium feature is open.

TO TEST THE IN-APP PURCHASE, PLEASE DO IT SIGNED OUT
The review account already has Premium, so it never sees the purchase screen. Buying needs no account: before signing in (or after Settings > Sign out), open Menu at the top right of Today, tap Premium, choose Monthly or Annual, and tap Go Premium. "Restore a purchase" is on the same screen.

AI AND THIRD-PARTY DISCLOSURE
Sort for me, Break it down and Scan send the text or photo the user chooses to Anthropic's Claude, only when the user taps one of them. A line naming Anthropic's Claude sits beside those buttons, the welcome offers an AI-free choice before anything runs, and Settings turns AI off entirely.

SHARED LIST (OURS)
A user can share one list with one other person by reading them a six-character code. There is no feed, discovery, profile or public content. "Report this list" and "Leave this list" are on the Ours screen, and we can disable any list server-side.

ACCOUNT DELETION
Settings > "Delete account and data". An Apple subscription is managed in the Apple ID settings, and the app says so before deleting.

DoubleDone is designed with ADHD, autistic and OCD users in mind. It makes no medical, diagnostic or treatment claim and collects no health data.
```
