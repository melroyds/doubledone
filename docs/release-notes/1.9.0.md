# 1.9.0 release notes (iOS and Android)

*One file per version. Apple takes What's New in EVERY App Store localisation: each one has its own field and
nothing inherits it. The earlier files said the localisations inherit the English. That was never true, and it
only never mattered because the App Store had English alone until this version. Play takes ONE paste with six
locale tags, each block at most 500 characters, real diacritics. Since 2026-10-18 Spanish is one neutral text,
pasted under both `es-419` and `es-ES`, which replaces 1.8.0's two variants.*

What 1.9.0 carries to the phones over 1.8.0 (iOS build 41 and Android versionCode 35, both from `13348bb`), for
the record:
- the store's own rating card after a good Close the day (`809086b`, `88f8c94`)
- a task's options without a finger, and the + stepping aside while a task is held (`2bb3c6f`, `8b78192`)
- the colour roles, light mode first, on Today and then on every screen (`96979ff`, `b7788ce`)
- the in-app truth strings (`460bd99`), and the iPhone welcome showing only Apple's price (`234a3b3`)
- the Terms' "Not medical care" section (`d795ebc`)
- the R11 merge fix for a task counted in parts (`5e76b6e`), already live on the web since the stepped-tasks push
- German in the phones' own language lists (`440e20c`)

The listing rewrite and the six captioned slides are console work, in `docs/appstore/` and the Play pack, not in
these notes.

**Left out of every block on purpose:** the rating card (never named in What's New or on Play, by the plan: a line
about it is a line of ours before the card), any price, currency, percentage, trial, Stripe or the website, the
Terms change, and the small wording fixes. Play also leaves out two of Apple's lines, for its cap (the Play
section says which). Feature names are the app's own catalogue words: Select several /
„Mehrere auswählen“ / «Seleccionar varias» / « Sélectionner plusieurs » / «Seleziona più attività», Options /
„Optionen“ / «Opciones» / « Options » / «Opzioni», Count it in parts / in Teilen zählen / contar por partes /
partie par partie / pezzo per pezzo, the Honey colour theme / „Honig“ / Miel / Miel / Miele, Light / hell / claro /
clair / chiaro, and Today / Heute / Hoy / Aujourd'hui / Oggi. The VoiceOver rotor is named as Apple names it in
each language (Actions, „Aktionen“, «Acciones», « Actions », «Azioni»), and TalkBack is TalkBack everywhere.

**Native read: done (2026-10-19).** The four translations were written for this file on 2026-10-19, after the
native read of the strings and listings had come back, to the catalogues' words and register: du, tú, tu and
tu, and one neutral Spanish (no vosotros, "teléfono" rather than móvil or celular, and the catalogue's own
"mantienes presionada" for a hold). The opening line of every block, on both stores, was scoped to the light
theme the same day (the colour review: dark mode got no darker, only its faintest grey lighter). Under call 7
they then had the localisations' one-reader-per-language read, the same day, which took them as they stood and
changed these, with every count below recounted by script:
- German, Play: TalkBack's line now names the action, "die Aktion „Optionen“", as the Apple block names
  „den Eintrag“, so the bare label no longer reads as a generic "offers options".
- Spanish: the two-finger Z closes "las" ("las mismas opciones"), where "lo" pointed at nothing. Honey's words
  go "a un tono bronce" so they "destaquen", which is "stand out", without three "color" in one clause. On Play,
  "volver atrás" replaces a bare "Atrás", in both Spanish blocks, which stay identical.
- French: both blocks open "Plus lisible", because "Tout se lit mieux" (everything reads better) claimed more
  than "Easier to read" and undid the light-theme scoping.
- Italian: "le stesse scelte di quando la tieni premuta" replaces a clumsy gerund.

Every cut-table opener below is unchanged, so the pre-decided cuts still line up. The French reader also
confirmed the listings' new Ours line, and the app's welcome (`sharedLead2`) now says it the same way.

Checked by script on 2026-10-19, with the counts beside each block:

## Before pasting: three sentences the device checks decide

The notes describe three things only a phone can prove. Each lives in a sentence that can be cut whole, so a
failed check costs a cut, never a rewrite, and the fix rides the next build (pre-decided, plan "Risks").

| If this case fails on the 1.9.0 build | Cut this sentence | From |
|---|---|---|
| A11Y-07 (VoiceOver's Options action) | the one that starts "With VoiceOver on" / „Mit VoiceOver“ / "Con VoiceOver activado" / « Avec VoiceOver » / "Con VoiceOver, ora" | all five Apple blocks, and the App Review notes (see below) |
| A11Y-08 (TalkBack's Options and back) | the one that starts "With TalkBack on" / „Mit TalkBack“ / "Con TalkBack, cada" / « Avec TalkBack » / "Con TalkBack, ogni", and the clause about back too if back is what failed | all six Play blocks |
| I18N-02 on an iPhone (German in the app's own Language setting) | the last sentence of each block, the one that starts "And German" / „Und Deutsch“ / "Y el alemán" / « Et l'allemand » / "E il tedesco" | all five Apple blocks (Play's notes never name it) |

**A failed A11Y-07 changes the App Review notes too.** Their second paragraph names the VoiceOver action, so it
then opens "Version 1.9.0 makes words easier to read and adds the App Store's own rating card (below)." The
rest of that paragraph stays, and the count in the notes' heading drops from 2646 to 2594. DEP-05 diffs the notes
as well as What's New.

### English (715 characters)

```
Easier to read. In the light theme, grey and coloured words are darker on Today and on the other screens, from Settings to the Calendar, and the Honey colour theme's coloured words turn bronze so they stand out clearly.

When you hold a task, the + at the bottom steps aside until you are done, so Select several is always in view. With VoiceOver on, every task now offers Options in the Actions rotor, the same choices as holding it, and a two-finger Z closes them again.

A task you count in parts now ends up done on every device as soon as its last part is ticked, even if it was changed somewhere else at the same time. And German joins the languages you can choose for DoubleDone in the iPhone's Settings app.
```

## Apple, App Review Information and notes

Sign-in required: **Yes**. User name `appreview@doubledone.app`. Password: `No password: one-time code, see notes`.
The same account and signed-out purchase path as 1.8.0, plus a RATING CARD paragraph (plan step 14.7: the card
comes through StoreKit's API only) and a last line that answers the new name before anyone asks. Every label
checked against `client/src/lib/catalogs/en.ts` and the Terms on 2026-10-19. 2646 characters.

```
DoubleDone is a calm daily to-do app for people who find a full task list overwhelming. The daily loop is free and needs no account. Premium adds optional extras.

Version 1.9.0 makes words easier to read, gives VoiceOver an "Options" action on every task, and adds the App Store's own rating card (below). The App Store name and subtitle now say who the app is designed for. Nothing about how purchases or sign-in work has changed.

RATING CARD
The app asks for the App Store's rating card only through StoreKit's own API (requestReview), with no prompt, button or words of our own before or after it. It asks at most once per app version, at least 180 days apart, after a user closes a good day. It needs five closed days spread over at least two weeks, so it will not appear during review.

REVIEW ACCOUNT (sign-in is passwordless)
1. On Today, tap "Sync and sharing".
2. Enter appreview@doubledone.app and tap "Email me a code".
3. In any browser, open https://api.doubledone.app/review-code. Use the 6-digit code on the line that starts "appreview@doubledone.app:".
4. Type it into the app. Codes last an hour. If none shows, tap send again in the app and refresh the page.
This account already has Premium, so every Premium feature is open.

TO TEST THE IN-APP PURCHASE, PLEASE DO IT SIGNED OUT
The review account already has Premium, so it never sees the purchase screen. Buying needs no account: before signing in (or after Settings > Sign out), open Menu at the top right of Today, scroll to the end of the page, tap Premium, choose Monthly or Annual, and tap Go Premium. "Restore a purchase" is on the same screen.

AI AND THIRD-PARTY DISCLOSURE
Sort for me, Break it down and Scan send the text or photo the user chooses to Anthropic's Claude, only when the user taps one of them. A line naming Anthropic's Claude sits beside those buttons, the welcome offers an AI-free choice before anything runs, and Settings turns AI off entirely.

SHARED LIST (OURS)
A user can share one list with one other person by reading them a six-character code. There is no feed, discovery, profile or public content. "Report this list" and "Leave this list" are on the Ours screen, and we can disable any list server-side.

ACCOUNT DELETION
Settings > "Delete account and data". An Apple subscription is managed in the Apple ID settings, and the app says so before deleting.

DoubleDone is designed with ADHD, autistic and OCD users in mind, and its name now says who it is for. It is a to-do list, not medical care: it makes no medical, diagnostic or treatment claim, collects no health data, and its Terms of Use say so in a "Not medical care" section.
```
