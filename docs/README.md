# DoubleDone documentation

A map of the written material in this repository. Each line says what a file is.

The first five groups are the reference docs: the product, the API, the engineering, the design and the releases. The last group, [Working records](#working-records), holds dated reviews, plans and audits. They are kept for their reasoning, and they describe the app as it was on the day they were written. Wherever a doc and the code disagree, the code is right.

DoubleDone is live on the web at [doubledone.app](https://doubledone.app), on the App Store and on Google Play. As of 5 October 2026, version 1.7.0 is live in both stores and 1.8.0 is with Apple and Google.

Findings may have been fixed since and plans may have changed, so none of them is the current state of the app. For that, read the groups above and the code.
