Connect Claude to DoubleDone

Let Claude add tasks, see your day, tick things off, and break a dreaded task into steps, all in your DoubleDone. It acts only as you, and it takes about a minute.

🔑

First, one thing: you need a DoubleDone account. If you have never signed in, open doubledone.app and sign in with your email once. A connector signs you in, it can't create the account for you.

In Claude (claude.ai or Cowork)

The easy path. Paste a link, sign in with a code, done. No token to copy.

  1. Open Settings → Connectors → Add custom connector.

  2. Name it DoubleDone, and paste this URL:

    https://api.doubledone.app/mcp

  3. Claude opens a small DoubleDone sign-in page. Enter your account email, then the 6-digit code it emails you.

  4. A consent screen shows exactly what it may do (add, list, and complete your tasks) and where access is sent. Read it, then click Allow.

  5. That's it. Ask Claude something like "what's on my DoubleDone today?"

◆ Nothing to re-paste later. The connection quietly refreshes itself, so it keeps working day to day.

Using Claude Code instead?

Developer clients connect with a token rather than the sign-in page. Grab yours in the app: Settings → AI agent access (MCP) → Copy my token (you must be signed in). Then run one line:

# paste your token where shown
claude mcp add --transport http doubledone https://api.doubledone.app/mcp \
  --header "Authorization: Bearer YOUR_TOKEN_HERE"

The token refreshes about hourly; if the agent ever stops connecting, re-copy it. (Cursor and the MCP Inspector work the same way, Streamable HTTP transport, same URL, same bearer header.)

Good to know

✓It only ever acts as you. The server holds no master key; every action runs under your own account's security and can't touch anyone else's tasks.
✓Break-it-down proposes, never adds. It shows you the steps and adds nothing until you say yes.
✓Delete is recoverable. A removed task is tucked away and syncs, never truly destroyed.
✓Disconnect anytime. Settings → AI agent access (MCP) → Disconnect AI connectors cuts access immediately.
