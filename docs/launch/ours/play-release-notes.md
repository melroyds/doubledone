# Play release notes, 1.3.1 (versionCode 26)

*Play caps each language at 500 characters. Counts below are real, measured, not estimated.*

## en-AU  (472 / 500)

```
Ours: one shared list with one other person.

Nothing on it says who did what, and nothing counts or compares, so it cannot become a scoreboard.

Anything with a day of its own, bin night on a Tuesday, arrives on both your Todays on the day. Everything else waits on the list, so nobody can make your morning heavier.

Tick it from either phone and it closes for both. Free, like the rest of the daily loop.

And a shared row's day can now be changed, or taken away again.
```

## If you only want one line

Play shows the first line collapsed, so it has to stand alone:

```
Ours: one shared list with one other person. Nothing on it says who did what, so it cannot become a scoreboard.
```

## Do not write

- "no data records who did what" (created_by exists server-side for abuse reports; the honest claim
  is that nothing SAYS who did what)
- anything about shared lists being new to iOS or web, since Play notes are read only by Android users
- exclamation marks, em-dashes, or the word "seamless"
